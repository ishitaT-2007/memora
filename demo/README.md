# Accrue demo pack (portable)

Copy **this entire folder** (`docs/demo`) to a USB or to your other PC’s Accrue git repo. Open the HTML files by double-clicking them — no install needed. Commit/push only on the machine that owns your git remote (not required from this PC).

| File | What it is |
|---|---|
| [DEMO_SHEET.html](./DEMO_SHEET.html) | **Image document** — annotated layout + exact static Ask queries |
| [DEMO_VIDEO.html](./DEMO_VIDEO.html) | **Demo video** — autoplay 8-step 60s demo walkthrough |
| [accrue-demo-layout.png](./accrue-demo-layout.png) | Annotated layout poster (embedded in the sheet) |
| [COPY_THIS_FOLDER.txt](./COPY_THIS_FOLDER.txt) | One-page copy instructions |

## Screen map (matches the live app)

| Column | What you show |
|---|---|
| **Left** | **Client details** (Client book): ARR, people, commitments, prior incidents |
| **Middle** | **Ask this company** — click the static chips below |
| **Right** | **Rescue brief** after **Run 60s demo** (Do/Don’t + unsent draft) |

## Static Ask queries (click these chips in the app)

1. What is Priya telling in this mail?
2. What did we promise Priya?
3. Who are the stakeholders?
4. What is this account's ARR?
5. Should we offer credits?
6. What happened with SSO?
7. What prior incidents does this account have?
